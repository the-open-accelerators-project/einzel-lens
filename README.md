# einzel-lens

Rechnet aus, wo eine elektrostatische Einzellinse einen Elektronenstrahl niedriger Energie (z. B. 24 eV) fokussiert, und erklärt dabei Schritt für Schritt die Physik dahinter.
Starten mit `pip install -r requirements.txt` und `python einzellinse_einfach.py`; die Eingaben (Bohrung, Ringlänge, Spalt, Strahlenergie, Spannungen) stehen oben im Skript.
